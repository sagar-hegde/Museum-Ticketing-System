# 🎟️ MTS – Museum Ticketing System

> 🚀 A modern, user-friendly, and eco-conscious digital ticketing solution designed to transform museum experiences. 

---

## 🌟 Overview

**MTS (Museum Ticketing System)** is an enhanced version of a paperless ticketing platform that replaces traditional ticketing with a **fully digital, QR-based system**.

With improved frontend design and better usability, MTS focuses on delivering a **smooth, intuitive, and efficient experience** for users.

---

## 💡 Problem Statement

Traditional ticketing systems create several challenges:

* ❌ Long queues and waiting times
* ❌ Need for physical presence to book tickets
* ❌ Contact-based risks in crowded areas
* ❌ Paper wastage and environmental concerns

---

## ✅ Solution

MTS provides a **smart and contactless ticketing system** with:

* 📱 Easy online ticket booking
* 🔐 Secure login system
* 📊 Real-time database integration
* 📷 QR-based ticket verification
* 🎨 Improved and user-friendly frontend

## ⚙️ How It Works

1. User logs in 🔐
2. Selects museum & time slot 🏛️
3. Enters visitor details 👥
4. Booking is stored in Firebase ☁️
5. QR code is generated 📷
6. QR is scanned at entry for validation ✅
